# Code de conduite

Ce projet applique le [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.

## Notre engagement

Dans l'intérêt d'un environnement ouvert et accueillant, les mainteneurs et les contributeurs s'engagent à faire de la participation à ce projet une expérience respectueuse, inclusive et constructive pour toutes et tous.

## Comportements attendus

- utiliser un langage accueillant et inclusif ;
- respecter les points de vue et expériences différents ;
- accepter les critiques constructives avec bienveillance ;
- se concentrer sur ce qui est le mieux pour le projet et ses utilisateurs ;
- faire preuve d'empathie envers les autres membres de la communauté.

## Comportements inacceptables

- propos ou images sexualisés, attaques personnelles ou politiques ;
- harcèlement public ou privé ;
- publication d'informations privées sans autorisation explicite ;
- insultes, intimidation, trolling ou commentaires dégradants ;
- tout comportement raisonnablement considéré comme inapproprié dans un cadre professionnel.

## Champ d'application

Ce code s'applique à tous les espaces du projet : issues, pull requests, discussions, documentation, interactions liées au dépôt et communications publiques associées au projet.

## Signalement

Les comportements inacceptables peuvent être signalés aux mainteneurs via les canaux publics du dépôt lorsque c'est approprié. Pour un signalement sensible, utilisez les coordonnées publiées dans le profil GitHub du mainteneur ou contactez-le en privé.

Tous les signalements seront examinés de façon équitable et confidentielle dans la mesure du possible.

## Application

Les mainteneurs peuvent supprimer, modifier ou rejeter des contributions ne respectant pas ce code. Selon la gravité ou la répétition des faits, ils peuvent limiter temporairement ou définitivement la participation au projet.

## Attribution

Ce code est adapté du [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
