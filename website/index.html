OUTILS IA

12 Outils pour explorer tout le basket français

Votre assistant IA sélectionne automatiquement le meilleur outil pour vous répondre avec une précision totale.

⚡

ffbb_team_summary

Le résumé ultime en un seul appel : bilan de la saison, position au classement, dernier résultat et prochain match à jouer.

🔴

ffbb_lives

Scores en temps réel, quarts-temps et statut des matchs en cours sur l'ensemble des championnats français.

🏆

ffbb_bilan

Bilan exhaustif d'une équipe toutes phases confondues : victoires, défaites, points marqués/encaissés et goal-average.

🏟️

ffbb_club

Fiche complète d'un club : calendrier des matchs du week-end, liste des équipes engagées et classements officiels.

🔍

ffbb_search

Recherche universelle et rapide : clubs, compétitions, tournois, gymnases, arbitres et terrains de basket 3x3.

📅

ffbb_next_match / last_result

Détails précis de la prochaine rencontre programmée ou de la dernière feuille de match jouée.

INTÉGRATION 1 CLIC

Connectez votre client IA préféré

Ajoutez l'URL Streamable HTTP officielle dans votre configuration et commencez immédiatement à poser vos questions.

// Dans .cursor/mcp.json ou Paramètres > Features > MCP
{
  "mcpServers": {
    "ffbb": {
      "url": "https://ffbb.desimone.fr/mcp"
    }
  }
}
// Dans claude_desktop_config.json
{
  "mcpServers": {
    "ffbb": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/client-sse", "https://ffbb.desimone.fr/mcp"]
    }
  }
}
// Dans settings.json de VS Code (Mode Agent GitHub Copilot)
{
  "github.copilot.chat.mcpServers": {
    "ffbb": {
      "url": "https://ffbb.desimone.fr/mcp"
    }
  }
}
// Dans mcp_config.json de Google Antigravity
{
  "mcpServers": {
    "ffbb": {
      "serverUrl": "https://ffbb.desimone.fr/mcp"
    }
  }
}

FAQ

Questions fréquentes

Tout ce que vous devez savoir pour démarrer et utiliser le serveur MCP.

Comment poser des questions sur le basket à mon IA ? +

Il suffit d'ajouter l'URL https://ffbb.desimone.fr/mcp dans votre client MCP (Cursor, Claude Desktop, Copilot). Votre IA saura automatiquement utiliser les 12 outils spécialisés pour vous répondre.

Quels types de questions sont compris ? +

Vous pouvez demander le classement d'une poule, le prochain match d'une équipe, le résumé complet de saison d'un club, les gymnases à proximité ou les scores des matchs en direct le week-end.

Faut-il installer Python ou cloner le projet ? +

Non ! L'instance publique https://ffbb.desimone.fr/mcp est hébergée et prête à l'emploi. Il vous suffit de copier l'URL dans votre configuration.

Les données sont-elles officielles et à jour ? +

Oui, toutes les données proviennent directement des flux officiels de la Fédération Française de BasketBall via le SDK ffbb-data-client avec une actualisation en direct pour les scores du week-end.
