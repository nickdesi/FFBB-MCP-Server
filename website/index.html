Recommandé pour GitHub Copilot

Installez FFBB Basketball MCP en quelques clics

Téléchargez le fichier .vsix depuis la dernière release, puis installez-le dans VS Code via Extensions → … → Install from VSIX…. L'extension enregistre le serveur public FFBB pour GitHub Copilot en mode agent.

Télécharger l'extension Installer sans extension

Option A (recommandé) : dans Claude, allez dans Paramètres → Connecteurs → Ajouter un connecteur personnalisé et saisissez l'URL https://ffbb.desimone.fr/mcp.
Option B : via le fichier de configuration de Claude Desktop (nécessite Node.js pour npx) : 

// claude_desktop_config.json
{
  "mcpServers": {
    "ffbb": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/client-sse", "https://ffbb.desimone.fr/mcp"]
    }
  }
}
# Installation automatique via Smithery CLI
npx -y @smithery/cli@latest install @nickdesi/mcpffbb \
  --client claude \
  --mcp-url https://ffbb.desimone.fr/mcp
// Cursor / VS Code — type : Streamable HTTP
{
  "mcpServers": {
    "ffbb": {
      "type": "http",
      "url": "https://ffbb.desimone.fr/mcp"
    }
  }
}

Questions fréquentes

FAQ

Comment interroger l'API FFBB avec l'IA ?

Avec VS Code, installez l'extension FFBB Basketball MCP depuis la dernière release GitHub : elle enregistre https://ffbb.desimone.fr/mcp pour GitHub Copilot en mode agent. Pour Claude, Cursor ou un autre client MCP, utilisez le transport Streamable HTTP avec la même URL.

Mon club de basket est introuvable, que faire ?

Essayez un libellé plus précis via ffbb_search : ville, nom officiel ou fragments distinctifs du club. Une fois l'ID FFBB trouvé, réutilisez-le pour les requêtes suivantes afin d'éviter les ambiguïtés.

Faut-il connaître l'ID FFBB ou le numéro d'équipe ?

L'ID FFBB est plus fiable que le nom du club. Pour une catégorie ambiguë comme U13M, utilisez ffbb_resolve_team ou précisez le numéro d'équipe.

Les données et scores sont-ils en temps réel ?

Les scores live utilisent un cache très court pendant les matchs. Les calendriers, classements et ressources FFBB utilisent une stratégie de cache adaptée au type de donnée afin de rester exploitables sans surcharger les services officiels.
