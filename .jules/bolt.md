## 2025-02-28 - Optimize Text Normalization with List Comprehensions
**Learning:** In CPython, when filtering or transforming characters to build a string via `"".join()`, using a list comprehension (`"".join([c for c in text if ...])`) is generally faster than using a generator expression. The list comprehension executes entirely in C and allows `join()` to pre-calculate the required string size, avoiding Python generator frame execution overhead and dynamic memory allocation. This yielded a ~11-15% performance improvement for accent stripping in `ffbb_mcp`. Additionally, be careful to use tuple syntax for handling multiple exception types in a single `except` block for Python 3.10+ (e.g., `except (ValueError, TypeError):`), to avoid `SyntaxError`.
**Action:** Replace generator expressions with list comprehensions when building strings with `"".join()` in performance-critical text normalization or parsing loops.
