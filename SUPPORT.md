# Support

## Avant de demander de l'aide

Consultez d'abord :

- [`README.md`](README.md) pour l'installation rapide ;
- [`docs/TOOLS_REFERENCE.md`](docs/TOOLS_REFERENCE.md) pour la référence des outils ;
- [`docs/EXAMPLES.md`](docs/EXAMPLES.md) pour les exemples d'usage ;
- [`docs/COOLIFY_DEPLOYMENT.md`](docs/COOLIFY_DEPLOYMENT.md) pour le déploiement.

## Où demander quoi ?

- Bug reproductible : ouvrez une issue avec le modèle "Bug report".
- Demande d'amélioration : ouvrez une issue avec le modèle "Feature request".
- Question d'usage : ouvrez une issue de question/discussion si le sujet peut aider d'autres utilisateurs.
- Vulnérabilité : suivez `SECURITY.md`, sans créer d'issue publique.

## Informations utiles

Merci d'inclure si possible :

- version du serveur ou commit utilisé ;
- mode MCP (`stdio` ou `streamable-http`) ;
- OS et version Python ;
- commande ou configuration utilisée ;
- sortie d'erreur minimale, sans secrets ;
- étapes de reproduction.

Le projet est maintenu sur du temps limité : les réponses ne sont pas garanties dans un délai fixe.
